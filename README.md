# weolbu-reader

개인 열람용 정적 사이트입니다. 모든 페이지는 [StatiCrypt](https://github.com/robinmoisson/staticrypt)로 암호화되어 있어 비밀번호 없이는 읽을 수 없습니다.

- 주소: https://toy-project-kyungsle.github.io/weolbu-reader/
- 처음 접속하면 비밀번호를 묻습니다. "이 기기에서 기억하기"를 켜면 그 기기에서는 다시 묻지 않습니다.
- 이 저장소의 파일은 비공개 원본 저장소의 배포 스크립트가 만듭니다. 직접 고치지 마세요. 다음 배포 때 모두 덮어써집니다.
